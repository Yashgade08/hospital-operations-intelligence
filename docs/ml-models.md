# ML models

## No-show prediction

Synthetic appointments are generated with pre-appointment features only. Logistic Regression and balanced Random Forest are compared using precision, recall, F1, and ROC-AUC on a stratified holdout. The higher-F1 fitted pipeline is saved to `ml/models/no_show_model.joblib`.

## Bed occupancy

Synthetic daily occupancy is sorted by date and evaluated on the final chronological 20 percent. A transparent trailing-seven-day baseline reports MAE, RMSE, and MAPE. This is deliberately a baseline, not a clinical or capacity guarantee.

Metrics are generated by the training scripts and should be reported from the resulting JSON artifacts after execution; this document does not invent values.
